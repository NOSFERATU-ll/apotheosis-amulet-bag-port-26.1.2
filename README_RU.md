# Apotheosis Amulet Bag

Сумка для амулетов зелий Apotheosis на Minecraft **26.1.2 NeoForge**.

## Возможности

- Вид мешочка зависит от содержимого: пустой, с одним, двумя или тремя видимыми амулетами. При трёх–пяти амулетах отображается полный мешочек.
- Пять слотов, открываемых последовательно за **100 / 200 / 300 / 400 / 500 уровней опыта**.
- Амулеты внутри включаются автоматически, дают эффекты и расходуют прочность.
- Работает в основном инвентаре, второй руке и слотах Curios.
- Одновременно работает первая подходящая непустая сумка.
- Принимает только амулеты зелий Apotheosis.
- Есть рецепт крафта, отображение закрытых слотов, русский и английский переводы.

## Управление

- **ПКМ** — открыть сумку.
- **Shift + ПКМ** — открыть следующий слот. В творческом режиме открытие бесплатно.

## Требования

Minecraft **26.1.2**, Java **25**, NeoForge **26.1.2.76+**, Apotheosis **9.1.x** и его обязательные зависимости. Curios **15.x** для 26.1.2 необязателен.

Мод устанавливается на клиент и сервер.
