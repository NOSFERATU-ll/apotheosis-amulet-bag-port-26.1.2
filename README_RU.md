# Apotheosis Amulet Bag — Minecraft 26.1.2

Порт сумки амулетов с версии 1.21.1 на **NeoForge 26.1.2**. Автор: NOSFERATU.

## Установка

Нужны Java **25**, Minecraft **26.1.2**, NeoForge **26.1.2.76+ для 26.1.2**, Apotheosis **9.1.x** и его обязательные зависимости. Curios **15.x для 26.1.2** необязателен; для разработки и проверок используется **15.0.0+26.1.2**.

Установите `apoth_talisman_bag-26.1.2-1.0.0.jar` в папку `mods` клиента и сервера. Зависимости скачиваются отдельно. Файл `-sources.jar` устанавливать в игру не нужно.

Поддержка 26.1, 26.1.1 и 26.2 не заявлена. Эта сборка предназначена для NeoForge.

## Использование

- ПКМ по сумке — открыть окно с пятью слотами.
- Shift + ПКМ — открыть следующий слот за **100 / 200 / 300 / 400 / 500 уровней**. Изначально все слоты закрыты; в творческом режиме открываются бесплатно.
- В открытые слоты можно класть амулеты зелий Apotheosis. Они включаются автоматически, дают эффекты и расходуют прочность по правилам Apotheosis.
- Сумка работает в основном инвентаре, второй руке или слоте Curios. Одновременно работает первая подходящая непустая сумка, в указанном порядке приоритета.
- Пока окно открыто, перемещение самой сумки через это окно заблокировано.

```mcfunction
/give @p apoth_talisman_bag:talisman_bag
```

ID предмета и ключи данных сумки сохранены, однако перенос существующих миров с 1.21.1 не проверялся.

## Сборка и проверки

На Windows с JDK 25:

```powershell
.\gradlew.bat build
.\gradlew.bat runSmokeServer
.\gradlew.bat runSmokeServer -PwithoutCurios
```

Готовый JAR находится в `build/libs`. Автоматические серверные проверки проверяют уровни, ограничения слотов, сохранение пяти амулетов, эффекты и расход прочности, сохранение износа при открытом окне, удаление предметов и Curios. При успехе создаются `build/smoke-curios.txt` и `build/smoke-no-curios.txt` со строкой `PASS:`. Проверяйте эти файлы: один только код выхода Gradle не гарантирует успех серверных проверок.

Тестовый мод не включается в итоговый JAR. Графику, клики настоящего игрока и синхронизацию в мультиплеере нужно дополнительно проверить в игре: [список проверок](TESTING.md).
