# Apotheosis Amulet Bag

A bag for Apotheosis potion charms on Minecraft **26.1.2 NeoForge**.

## Features

- The bag appearance follows its contents: empty, one, two, or three visible charms. Three to five stored charms use the full appearance.
- Five charm slots, unlocked progressively for **100 / 200 / 300 / 400 / 500 experience levels**.
- Stored charms activate automatically, apply their effects and consume durability.
- Works in the main inventory, offhand and Curios slots.
- Only the first eligible nonempty bag is active.
- Accepts Apotheosis potion charms only.
- Includes a crafting recipe, locked-slot indicators and English/Russian translations.

## Controls

- **Right-click** — open the bag.
- **Sneak + right-click** — unlock the next slot. Unlocking is free in creative mode.

## Requirements

Minecraft **26.1.2**, Java **25**, NeoForge **26.1.2.76+**, Apotheosis **9.1.x** and its required dependencies. Curios **15.x** for 26.1.2 is optional.

Install the mod on both client and server.
